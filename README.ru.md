# Coddy for Browser

Расширение Chrome, через которое ваш собственный агент [Coddy](https://github.com/coddy-project/coddy-agent)
работает в браузере, которым вы пользуетесь каждый день. С Coddy можно переписываться в боковой панели рядом со
страницей, а можно дать браузер любому другому чату Coddy - в веб-интерфейсе, консоли, Telegram или задании
планировщика. Чат открывает вкладку, читает страницу, кликает, печатает, делает скриншоты и переносит файлы, а
расширение выполняет это во вкладках, которые вы ему дали.

[English version](README.md)

Расширение общается только с сервером Coddy, адрес которого вы указали. Модель работает на этом сервере, расширение
выполняет действия и спрашивает вас, прежде чем Coddy впервые возьмётся за новый сайт.

## Как это устроено

```
 чат Coddy --> инструмент browser --> coddy serve  <==== WebSocket (JSON-RPC 2.0) ====  Coddy for Browser
                                      слушатель          открывает расширение             (это расширение)
                                      :12348                                                    |
                                                                                                v
                                                                              ваши вкладки в группах Coddy
```

- **Соединение открывает расширение.** Оно держит один WebSocket к слушателю браузера в `coddy serve`. Действия
  Coddy приходят по этому сокету запросами, на которые расширение отвечает, поэтому Coddy достаёт до браузера, к
  которому у сервера нет маршрута, и ноутбук за NAT работает так же, как браузер на самом сервере;
- **чат рядом со страницей.** Кнопка расширения на панели открывает боковую панель с чатом вашего Coddy. Вкладка, из
  которой вы пишете, попадает в группу этого чата, поэтому просьбы "перескажи эту страницу" или "заполни эту форму"
  работают со страницей перед вами. Перед инструментом с побочными эффектами Coddy спрашивает разрешение в панели, а
  сам чат - обычная сессия Coddy, которую можно продолжить в веб-интерфейсе;
- **что видит Coddy, решают группы вкладок.** Coddy видит только вкладки в своих группах Chrome. Чтобы дать вкладку
  всем чатам, нажмите **Share** в боковой панели или перетащите вкладку в группу **Coddy**. Чат, который начал
  работать в общей вкладке, переносит её в собственную группу с названием чата, и другие чаты там действовать не
  могут. Вкладка, которую открыл Coddy, сразу попадает в группу чата. Чтобы забрать вкладку, вытащите её из группы
  или нажмите **Take back**;
- **сайты одобряете вы.** Перед первым действием на сайте небольшое окно расширения спрашивает, разрешить ли его для
  этого чата, разрешить всегда или отказать. Страница не может ответить на этот вопрос за вас;
- **остановить можно в любой момент.** Кнопка остановки в заголовке боковой панели или кнопка Stop на странице, где
  работает Coddy, отменяет все действия и распускает все группы, а вкладки остаются открытыми.

Протокол описан в документации Coddy на странице [Протокол браузера](https://coddy.dev/docs/reference/browser-protocol).
Сторона Coddy и её настройка описаны на странице [Coddy for Browser](https://coddy.dev/docs/features/browser).

## Что нужно

- Chrome 116 или новее. Другие браузеры на Chromium могут загрузить расширение, но проверяется только Chrome;
- `coddy serve`, собранный с тегом `browser`. Он есть в бинарниках релиза, в Docker-образе и в пакетах;
- слушатель браузера, включённый в `config.yaml` Coddy, с ключом не короче 32 символов.

```yaml
browser:
  enable: true
  host: 127.0.0.1
  port: 12348
  token: ${CODDY_BROWSER_KEY}
```

Ключ сгенерируйте командой `openssl rand -hex 32` и положите в `<home>/.env` как `CODDY_BROWSER_KEY`. Для сервера
на другой машине привяжите слушатель к доступному адресу и задайте `cert_file` и `key_file` или поставьте перед ним
HTTPS-прокси, который пропускает переход на WebSocket. Простой HTTP расширение принимает только для `localhost`,
`127.0.0.1` и `[::1]`.

## Установка

Из релиза:

1. Скачайте `coddy-for-browser-<version>.zip` со страницы
   [Releases](https://github.com/coddy-project/coddy-for-browser/releases) и распакуйте в папку, которую не удалите;
2. откройте `chrome://extensions`, включите **Developer mode** и нажмите **Load unpacked**, затем выберите эту папку.

Из исходников нужен Node.js 22 или новее, пакеты ставить не надо.

```bash
npm run build
```

Потом загрузите папку `dist/chrome` тем же способом.

## Подключение

Страница настроек открывается после установки, а позже из кнопки настроек в боковой панели. Введите адрес
слушателя (`http://127.0.0.1:12348` для локального сервера), ключ и имя этого браузера, например `Chrome - laptop`,
и нажмите **Save and connect**. Имя различает браузеры, когда к одному серверу подключено несколько, и чат выбирает
среди них.

## Работа

Нажмите кнопку расширения и напишите в боковой панели, находясь на странице, с которой должен работать Coddy.

> Перескажи эту страницу и перечисли сроки, которые в ней упомянуты.

Панель показывает ответ по мере генерации, вызовы инструментов по мере выполнения и вопросы Coddy, например
разрешить инструмент или выбрать ответ. Кнопка с часами показывает чаты панели, плюс начинает новый.

Из любого другого чата Coddy дайте вкладку или позвольте Coddy открыть её самому и попросите, например так.

> Открой список пул-реквестов coddy-project/coddy-agent и скажи, какие ждут ревью.

Чат вызывает инструмент `browser`. Он смотрит доступные вкладки, читает страницу как текст со ссылками на элементы,
кликает и печатает через отладчик Chrome, поэтому ввод доверенный, как у человека, и прикладывает скриншоты, если
модель чата читает изображения. Пока Coddy работает во вкладке, она подсвечена и показывает кнопку Stop, а название
группы чата начинается с песочных часов.

## Разрешения

| Разрешение | Зачем |
| --- | --- |
| `tabs`, `tabGroups` | Читать вкладки в группах Coddy, открывать и группировать вкладки для чата. |
| `scripting` | Читать страницу и находить элементы по ссылкам, показывать индикатор работы. |
| `debugger` | Доверенные клики, ввод текста и клавиш, скриншоты через протокол DevTools. Пока отладчик подключён, Chrome показывает полосу, а расширение отключается через 20 с после последнего действия. |
| `storage` | Настройки подключения и сайты, которые вы разрешили. Ключ доступен только страницам самого расширения. |
| `alarms` | Будить service worker, чтобы переподключиться после того, как Chrome его остановил. |
| `notifications` | Сообщить, что Coddy просит доступ к сайту. |
| `sidePanel` | Чат рядом со страницей. |
| `http://*/*`, `https://*/*` | Действовать на сайтах, которые вы разрешили, и достучаться до вашего сервера Coddy. |

Расширение ничего не отправляет никуда, кроме вашего сервера Coddy. Страницы, которые читает Coddy, всё равно
попадают к провайдеру модели, настроенному на вашем сервере.

## Разработка

```bash
npm test                      # модульные тесты, только Node
npm run build                 # dist/chrome и dist/coddy-for-browser-<version>.zip
npm i --no-save playwright    # один раз, для сквозного прогона
npx playwright install chromium
npm run e2e                   # собранное расширение в настоящем Chromium против имитации Coddy
```

`CODDY_BROWSER_PATH` указывает сквозному прогону на установленный Chromium вместо браузера Playwright,
`CODDY_SCREENSHOT_DIR` собирает скриншоты страниц расширения.

Изменение протокола вносится в оба репозитория, в расширение и в `external/browser` в coddy-agent, вместе со страницей
протокола в том же изменении.
